# Claude Session Manager

**Định hướng:** VS Code Extension theo dõi và quản lý session của Claude Code trong VS Code.

**Tính năng chính:**
- 🤖 Theo dõi session Claude Code với runtime PID tracking
- 📊 Dashboard thời gian thực (Running, Need Accept, Done)
- 🔍 Phân tích token, branch git, repo
- 🎯 Issue tracking (#xxxx) và chat tự do
- 📱 Hiển thị trên Activity Bar, Explorer, Source Control

**Mục tiêu:** Giúp developer làm việc hiệu quả với Claude Code mà không bị lạc session.

**Trạng thái:** ✅ Production-ready - Đã release trên GitHub.
